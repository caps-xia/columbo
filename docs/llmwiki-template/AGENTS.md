# AGENTS.md — 排查知识库（llmwiki）分拣规矩

> 本文件是知识库的"库规"：任何 AI 助手（或人）在本库内做整理、分拣、体检前，必须先完整读完本文件并严格照办。

## 库结构

```
llmwiki/
├── AGENTS.md          ← 本文件（库规）
├── index.md           ← 全库索引：各业务线的速记清单（分拣后同步更新）
├── log.md             ← 分拣/整理操作日志（最新在最上）
├── 00-Inbox/          ← 收件箱：排查助手沉淀的原始速记（分拣的入口）
├── 10-Systems/        ← 按业务线归档的速记（一个业务线一个目录）
└── 20-Patterns/       ← 可复用套路提炼
    ├── concepts/      ← 通用坑/通用教训（概念页）
    └── snippets/      ← 日志查询命令/定位技巧（操作页）
```

## 速记格式

文件名固定 `速记-YYYYMMDD-问题简述.md`，**分拣时不改文件名**（只移动）。正文按章节组织：

```markdown
---
tags: [订单, 下单失败]
date: 2026-01-15
system: 订单交易
---

# 下单失败-库存扣减为 0 未拦截

## 现象
## 环境（业务线 + 系统 + 分支）
## 排查过程（查了什么、怎么定位的，简明）
## 根因
## 解决方案
## 置信度与依据
## 关联（关键文件:行号、traceId 示例——traceId 只保留前 8 位）
```

缺 frontmatter 的速记按上述模板补齐（tags/date/system）再归档。

## 分拣红线（先于一切）

1. **密钥与凭证零容忍**：密码/密钥/Token/账号口令/连接串一律不许入库，发现即删除该片段并在汇报中指出。
2. **个人信息脱敏**：手机号（139****5321）、身份证、银行卡号一律脱敏后再入库。
3. **内网信息脱敏**：内网域名/真实 IP 入库前替换为 `内网域名A`、`10.x.x.x` 这类占位。
4. **两份资料冲突时不覆盖**：并排放置、各自注明出处和日期、留一行"⚠️ 待人工裁决"，不擅自二选一。

## 置信度门槛（分拣侧二次防线）

速记的「## 置信度与依据」章节必须写明档位。分拣时复查：

- **高（≥85%）**：正常归档、提炼 Pattern；
- **中/低（<85%）或标注"疑似/待验证"**：**不归档、不提炼 Pattern**，移动到 `00-Inbox/_待复核/`（文件名不变），汇报中列出——错误结论入库会误导后续排查，宁可少记不可错记；
- 待复核速记在后续排查中被确认（人工复核，或新一轮高置信度速记覆盖同一结论）后，把原速记的置信度章节更新升档，再按常规归档；
- 新旧速记结论冲突且各自高置信：按「分拣红线 4」并排放置等人工裁决，不算待复核。

## 归类判据

按**问题业务内容**归类（不按环境/区域硬分）。判据拿不准就归"公共平台"并说明：

- 问题的业务名词命中某个 `10-Systems/<业务线>/` 目录主题 → 归该目录；
- 跨系统的排查工具/通用问题（网关、鉴权、日志切面、公共组件）→ `10-Systems/公共平台/`；
- 移动用 `mv`（本库不是 git 仓库），移动后把 frontmatter 的 `system` 改为目标业务线。

## Pattern 提炼（20-Patterns）

速记里的**可复用套路**提炼成 Pattern 页：通用坑/教训 → `concepts/`；查询命令/定位技巧 → `snippets/`。

- 动手前先查重：读 `index.md` 与 20-Patterns 现有页，已有现成页就**更新那页**（补链新速记），没有才开新页；
- 新 Pattern 页：页首一两句说明讲什么，页尾注明来源（哪天、哪个业务线、来自哪条速记）；
- 双链一律 `[[真实文件名]]`（不带 .md）；不确定目标存在就先列出问用户，**不要造空链**。

## 参考资料页不动

frontmatter `tags` 含 **导入** 或 **排查参考** 的页面是外部导入的参考资料：不参与分拣、不重写、不改格式。

## 同步动作（每次分拣必做）

1. `index.md`：对应业务线行的速记链接用 ` · ` 追加到行末；新 Pattern 页补进 20-Patterns 表；
2. `log.md`：记一笔（`## YYYY-MM-DD` 标题，最新在最上、紧跟文件头说明之后），一句话写清楚动了什么。

## 体检（每周可选）

三项检查：① 空双链（`[[链接]]` 指向的页面不存在，注意跳过说明文字里反引号内的示例）；② 孤立页（只进不出的速记/概念页）；③ 说法冲突（不同页面对同一问题结论矛盾，按红线 4 处理）。发现逐条列出：位置、问题、建议，等用户确认再改。

## 纪律

- 只处理本次待分拣文件，不重编全库；
- 拿不准归属的留 `00-Inbox/` 或归公共平台并说明；
- 全程中文；除分拣必需的移动/编辑外，不改库内任何其他内容。
