# 00-Inbox：收件箱

排查助手在根因闭环后会调用 `appendKnowledgeNote` 把速记写到这里（`troubleshoot.knowledge.inbox-dir` 配置，默认 `00-Inbox`）。

- 这里的文件是**待分拣**状态：每天用 `daily-triage-prompt.md` 跑一次分拣（交给你的 AI 助手），按 `AGENTS.md` 的规矩归档到 `10-Systems/`、提炼到 `20-Patterns/`；
- 文件名保持 `速记-YYYYMMDD-问题简述.md`，分拣只移动不改名；
- 未验证的推测不要入库（助手侧已拦截；人工补记时同样遵守）：排查助手只在高置信度（≥85%）且证据闭环时才沉淀，中/低置信度结论留在报告里等复核；
- 分拣时发现中/低置信度速记会被移入 `_待复核/`，等人工复核升档后再归档。
