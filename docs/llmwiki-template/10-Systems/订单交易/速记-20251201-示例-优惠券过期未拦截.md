# 优惠券过期未拦截-下单用了已过期券

## 现象
用户用一张已过期的优惠券下单成功，账实不符。订单服务日志中该订单的券校验只有 INFO 记录、无拦截。

## 环境
订单交易 / order-service（master 分支）

## 排查过程
1. 按订单号查订单服务日志：`couponCheck` 返回 pass；
2. `searchCode` 定位校验逻辑：只校验了券状态（有效），未校验 `expire_time` 与当前时间；
3. 复核券表数据：该券 `expire_time` 早于下单时间 3 天。

## 根因
`CouponChecker` 校验缺失过期时间比较——"有效状态"与"未过期"是两个条件，只查了前者。

## 解决方案
校验补 `expire_time > now` 条件；存量脏数据按主键定位修复（已给出 SQL，人工审批后执行）。

高（92%）：日志 + 代码 + 库内数据三方一致。
