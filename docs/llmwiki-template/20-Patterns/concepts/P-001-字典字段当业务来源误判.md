# P-001 · 字段语义以代码为准，别按字段名猜业务来源

状态/类型/来源类字段（`order_from`、`source`、`xx_type` 这类），**禁止凭字段名或取值推断业务含义**——字段值可能只是某个字典/ERP 标识，与"谁操作的、从哪来的"完全无关。

正确姿势：`searchCode` 读该字段的枚举定义与**全部写入点**，枚举完写入方再下结论；"东西从哪来/谁操作的"类问题尤其如此。

典型翻车：一个字典标识字段的取值被当成"三方推送订单"的证据，实际只是店铺 ERP 的字典值——结论整条作废。
