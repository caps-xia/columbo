# S-001 · CLS 两跳追踪法

排查报错链路的检索套路：**第一跳**按报错关键词 + ERROR 级别定位（条件放宽先探量）；**第二跳**取该 ERROR 的 contextId/traceId 拉全链路、**不带级别过滤**。

为什么第二跳必须去掉级别过滤：请求入参与三方接口的响应多为 INFO 级，漏看会把三方返回 `success:false` 误判成我方内部校验问题——而链路里三方响应 `success:false` 常直接就是根因。

配套动作：对关键异常日志用上下文检索（`queryClsLogContext`）取锚点前后各 10 条，判断是偶发还是链路必经故障。
